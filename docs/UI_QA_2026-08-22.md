# PiHub Investor UI QA — 2026-08-22

Scope: authenticated workspace shell, Products / Opportunity Book, Credit Requests, Invested Positions, Profile, Add/Edit Product, command palette and auth surfaces.

## Production screenshot findings

1. **Critical cascade collision — sidebar hover**
   - Legacy `style.css` applies `background-color` to `.nav-sidebar > ul > li:hover`.
   - The analytical sidebar keeps all workspace links inside that outer list item, so hovering any descendant paints the entire navigation block blue.
   - Fixed by explicitly neutralizing the legacy parent hover/current-menu background inside `.ap-sidebar` and keeping state styling only on the active `.ap-nav-item`.

2. **Critical readability regression — analytical UI is underscaled**
   - Multiple operational labels and values were 7–10px on desktop.
   - Credit amounts, statuses, table metadata, command items, profile contacts and form labels were affected.
   - Corrected to a practical 9–14px analytical scale, with 16px inputs on narrow mobile layouts.

3. **Header alignment vulnerable to legacy rules**
   - The new top bar depended on inherited layout behaving perfectly across old stylesheets.
   - Added explicit grid placement and float/margin neutralization for context and account actions.

4. **Desktop / tablet compression**
   - Inspector + dense ledger stayed side-by-side too long and squeezed the main data surface.
   - Inspector now stacks into a three-column analysis strip below 1320px, then becomes a normal block on smaller screens.

5. **Form controls below comfortable interaction size**
   - Several analytical/legacy fields and actions were 36–38px high.
   - Standardized core forms/actions to 42–48px, with mobile controls at 44px+.

6. **Small-label contrast**
   - The former `--ap-ink-400/500` colors were too light for 7–10px labels on the fog surface.
   - Darkened those semantic tokens. Contrast validation against `#f6f8fa` is now >=4.5:1 for the small label tokens used by the QA override.

7. **Horizontal data layouts**
   - Tables remain horizontally scrollable on narrow screens rather than compressing financial columns into unreadable fragments.
   - Added overscroll containment and touch scrolling behavior.

8. **Command palette / profile / empty states**
   - Several secondary text sizes remained under 9px after the first redesign pass.
   - Raised them and preserved the existing keyboard/focus behavior.
